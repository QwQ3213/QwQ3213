## `> whoami --verbose`

I build software because I'm curious about how things work — and even more curious about how I can make them work better.

My interests don't fit neatly into one category.

I enjoy creating interfaces, designing backend systems, connecting AI agents to real-world tools, and managing the infrastructure behind it all.

Sometimes I'm building a complete application from scratch. Other times, I'm experimenting with an unfamiliar technology, automating a repetitive task, or trying to understand why a perfectly working service suddenly stopped working.

I don't see frontend, backend, AI, and infrastructure as separate worlds.

To me, they're different pieces of the same puzzle.

**What matters most isn't how many technologies I know — it's what I can build with them.**

## `> areas_of_interest`

### 01 / Full-Stack Engineering

Building applications from the interface to the infrastructure.

I enjoy working across the entire development process, whether it's creating responsive user interfaces, designing APIs, implementing business logic, or connecting everything into a functional system.

**Areas I work with:**
- Modern frontend applications
- Backend services and REST APIs
- Full-stack application architecture
- Third-party API integrations
- Developer tools and utilities

### 02 / AI Agents & Automation

I'm particularly interested in AI systems that go beyond generating text.

AI becomes much more useful when it can interact with external tools, access structured information, and execute meaningful workflows.

I explore:
- AI agent development
- Model Context Protocol (MCP)
- Tool calling and external integrations
- Agent-driven workflows
- Task automation and orchestration
- Connecting AI systems with existing applications

**An AI agent shouldn't just explain how to do something. With the right tools and permissions, it should be able to get things done.**

### 03 / Bot Development

I enjoy building bots that connect messaging platforms with useful services and automated workflows.

Platforms I work with:
- Telegram Bots
- WeChat Bots
- QQ Bots

My interests include API integrations, event-driven systems, task processing, and connecting bots to external services.

### 04 / Infrastructure & Self-Hosting

I like having control over the systems I build and the environments they run in.

From deploying applications to maintaining Linux servers and containerized services, infrastructure is an important part of my development workflow.

Things I enjoy working with:
- Arch Linux and Linux environments
- Docker and containerized deployments
- VPS administration
- NAS and self-hosted services
- Cloudflare Workers
- Networking and service management

**If I can host it, configure it, and understand how it works, there's a good chance I'll experiment with it.**

## `> cat philosophy.txt`

I don't learn technologies just to collect names for a skills list.

I learn them because there's a problem I want to solve, a system I want to understand, or an idea I want to bring to life.

I believe good engineering is about making thoughtful decisions, understanding trade-offs, and knowing when simplicity is more valuable than complexity.

Not every problem needs a complicated architecture.

Not every project needs the newest framework.

And not every interesting experiment needs to become a product.

**Build what matters. Understand what you build. Keep improving it.**
